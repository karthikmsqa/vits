# Vancouver Island Tamil Sangam (VITS)

Community website for Tamil families, students and newcomers in Greater Victoria and across Vancouver Island, British Columbia.

## Website

GitHub Pages: https://karthikmsqa.github.io/vits/ (available after Pages is enabled)

## Pages

- `index.html` — Home
- `about.html` — About VITS and community activities
- `culture.html` — Tamil culture and heritage
- `newcomers.html` — Newcomer settlement resources
- `students.html` — Student guide
- `calendar.html` — Tamil calendar and Panchangam resources
- `contact.html` — Community contact form
- `credits.html` — Credits

## Deployment

In the repository, open **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)** and save.

For a custom domain, configure the domain under GitHub Pages settings and point DNS records to GitHub as instructed there. Do not add a `CNAME` file until the domain is owned and confirmed.

## Contact form

The contact form uses a third-party form handler for testing, targeting `km.acdqa@gmail.com`. The recipient must verify/activate the service and test form delivery. GitHub Pages does not process forms on its own.

## Maintaining the website

This is a static HTML/CSS/JavaScript site. Edit the page files and `assets/` on the `main` branch to publish changes. Verify local services, calendars, community-program schedules, external links, and licenses before promoting information publicly.

## Status

This is a draft community resource website. VITS program descriptions, event schedules, and social group links should be confirmed by organizers before launch.
